# 제15회 변호사시험 공·민·형 평가 — GPT-6 Sol / High

2026년 9월 23–25일, **GPT-6 Sol · 추론 강도 High**로 제15회 변호사시험 선택형 공법 40문항·민사법 70문항·형사법 40문항을 평가했다. 과목마다 도구 미사용(OFF) 3회와 법률 검색 도구 사용(ON) 3회를 실행했다.

| 과목 | 문항 수 | 도구 미사용 1·2·3회 | 도구 사용 1·2·3회 | 평균 정답률 OFF → ON |
|---|---:|---|---|---|
| [공법](cleanroom_gpt6sol_high/REPORT.md) | 40 | 34 · 35 · 34 | 40 · 40 · 40 | 85.83% → 100.00% |
| [민사법](civil_gpt6sol_high/REPORT.md) | 70 | 60 · 54 · 55 | 66 · 67 · 68 | 80.48% → 95.71% |
| [형사법](criminal_gpt6sol_high/REPORT.md) | 40 | 33 · 31 · 30 | 39 · 39 · 39 | 78.33% → 97.50% |

각 과목의 같은 회차 번호를 단순 합산하면 OFF는 **127·120·119/150**, ON은 **145·146·147/150**이다. 평균은 **122/150(81.33%) → 146/150(97.33%)**, 차이는 **24문항·16.00%p**다. 과목별 실행을 사후 합산한 값이며, 150문항을 한 세션에서 연속 응시한 결과는 아니다.

## 어떤 비교인가

- 공법 ON은 세 프레이밍의 다수결과 선별 추가 검토를 포함한 **최종 답안**이다. 1차 다수결도 세 회 모두 40/40이었으며 추가 검토로 선택 답안은 바뀌지 않았다.
- 민사법·형사법 ON은 **1차 답안** 점수다. 저신뢰 문항의 별도 2차 검토는 본 점수에 반영하지 않았다. 민사법 재검토를 반영한다고 가정하면 68·68·68/70, 형사법은 39·39·39/40이다.
- 도구 사용 조건은 Korean-law MCP, 시험용 교재 검색 DB, 판례 검색 및 검색 지침을 함께 사용했다. 따라서 차이를 **도구 하나만의 독립 효과**로 해석할 수 없다. 과목별 도구·절차 차이는 각 보고서와 환경 기록에 적었다.

## 채점표와 해석의 한계

1. **공법**: 실제 사용한 정답 JSON은 정답가안이라고 표기한다. 참조 저장소 NOTICE의 확정 정답 출처 표시와 불일치한다. **민사법**: 참조 저장소 NOTICE가 확정 정답 변환본으로 명시한다. **형사법**: 사전등록된 정답가안 변환본을 사용했다. 이번 공개 작업에서는 세 과목 채점표를 법무부 확정 정답 원문과 별도로 대조하지 않았다. 공개 점수는 포함된 채점표에 대한 재계산 결과다.
2. 공법·민사법은 계획한 답안 봉인 후 정답표를 열었다. **형사법은 첫 OFF/ON 한 쌍과 진단 회차를 이미 채점한 뒤, 계획을 수정하여 2·3회차를 추가했다.** 추가 풀이에는 기존 답안·정답표·조정자 대화를 전달하지 않았다. 전체 3회가 최초 정답 공개 전에 끝났다고 주장하지 않는다.
3. 새 세션·별도 작업폴더·도구 제한·로그 검사에 의한 논리적 격리다. 운영체제 수준 읽기 차단은 적용하지 않았다. 조정자가 본 참조 자료의 범위는 과목별 보고서에 밝혔다.
4. 같은 공개 문제를 반복했다. 3회 결과는 서로 다른 신규 문제 450개의 평가가 아니며, 학습 데이터 노출 부재·다른 시험 성능·변호사시험 전체 합격을 입증하지 않는다. 법률 근거의 타당성을 사람이 전수 검증한 결과도 아니다.
5. 사전등록 문서는 실행 전에 작성한 **로컬 기록의 사후 공개본**이다. 이 통합 저장소의 공개 시점은 실행 이후이며, 로컬 커밋 번호와 봉인 시각 자체가 외부 타임스탬프 인증을 뜻하지는 않는다.

## 공개 자료와 재검산

과목 폴더에 보고서, 결과 JSON, 문제, 채점표, 봉인 답안, 사전등록·수정 기록, 환경 및 검증 기록을 모았다. **18개 1차 답안과 세 채점표는 원본 바이트를 유지**했다. 일부 문서·메타데이터는 로컬 사용자 경로를 `/LOCAL_USER`로 치환했고, 보고서 링크는 저장소 안에서 열리도록 바꿨다. 공법 보고서의 정답표 표현도 바로잡았다. 파일별 원본·공개본 해시는 [공개 목록](PUBLICATION_MANIFEST.json)에 있다.

교재·DB·임베딩, 검색 결과 전문이 담긴 원시 로그, 실행 슬롯, 로컬 Git 이력은 포함하지 않았다. 봉인 기록에 열거된 비공개 파일의 해시는 보존용 참조이며, 그 파일 전체가 이 저장소에 있다는 뜻은 아니다. 공개된 메타데이터는 당시 점검 기록이며 원시 로그의 독립 재감사를 대신하지 않는다.

추가 패키지 없이 Python 3으로 점수·봉인 답안 해시·공개 파일 해시·로컬 문서 링크를 확인할 수 있다.

```sh
python3 verify.py
```
