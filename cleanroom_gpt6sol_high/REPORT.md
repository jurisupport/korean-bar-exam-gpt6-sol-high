**실행 조건과 검증**

- 모든 유효 평가 호출은 `gpt-6-sol`, 추론 강도 `high`, 새 비대화 세션으로 실행했다. OFF 15회, ON 1차 45회, 추가 검토 70회로 총 130회이며 작업 폴더도 모두 별개다.
- 원 실험의 모델·강도 `gpt-5.6-sol / xhigh`를 요청한 `gpt-6-sol / high`로 바꿨다. OFF는 연구 도구를 제외하기 위해 사용자 설정을 로드하지 않았다. ON은 설치된 Korean-law MCP 4.14.0을 고정해 사용했다. 최신 MCP의 법령 연혁·인용 확인 등 보조 조회도 추가 검토 로그에 기록돼 있다.
- 시험용 교재 DB는 18개 문서·17,167개 임베딩, 판례 DB는 선고일 2026-01-05 이하의 3,310개 문서·34,788개 임베딩으로 복구했다. 판례 접속 포트만 8770에서 8772로 옮겼다. 두 DB 파일의 실행 전후 SHA-256은 일치한다. 원 저장소에 과거 DB의 파일 해시가 공개되지 않았으므로 역사적 파일의 바이트 단위 동일성까지 확정하지는 않았다.
- 일반 교재 DB와 사건기록 DB를 대신 사용하지 않았다. 1차 풀이 로그의 셸 네트워크 대상은 시험용 교재 DB 8768뿐이었고, MCP는 Korean-law만 사용했다.
- OFF 3회 로그에서 외부 검색·DB 호출 기록이 발견되지 않았다. ON 로그에서도 WebSearch 및 정답표 읽기 기록이 발견되지 않았다. 정답표 경로가 들어간 파일 검색 명령은 모두 해당 경로를 제외하는 패턴이었다.
- 교재 검색 출력 1,661건에서 제15회/2026 변호사시험을 직접 가리키는 제한된 문구 검색은 0건이었다. 이 점검은 간접적인 해설 중복이나 학습 노출을 전부 배제하는 검사는 아니다.
- 문항 누락·중복, 답 범위, 모델 설정, 봉인 해시와 쓰기 잠금, 추가 검토 대상의 누락·중복·다른 문항 변경을 점검했다. 실행 전 자체 검사와 Python 구문 검사도 통과했다.
- 정답표 다운로드 시각: **2026-09-23 07:05:52 KST**. 여섯 봉인본의 해시를 확인한 뒤 다운로드했고, 원 저장소 무결성 목록과 정답표 SHA-256을 대조한 다음 일괄 채점했다.
- 모델·포트·API 이름 등 실행 환경의 차이와 추가 검토 대상의 자동 추출 방식은 ON 시작 전에 별도 사전등록했다. 점수를 보고 회차를 선택하거나 답안을 수정하지 않았다.

**보존한 기술 오류와 복구**

1. 최초 ON 1회차 첫 5개 호출 중 일부에서 선택적 MCP 초기화 대기 문제로 법령 도구가 노출되지 않았다. 최초 5개를 전부 기술 실패로 분리·보존하고, 도구 초기화를 필수로 기다리도록 설정한 뒤 다시 실행했다. 답안이나 점수에 따른 선택은 없었다.
2. F3의 31번 검토 파일이 범위 밖인 2·3번의 `gap_class` 표시를 서로 바꿔 병합 검사에서 차단됐다. 원본 출력은 보존했고, 해당 두 표시만 원상복구한 대상 문항 전용 파일을 만들었다. 31번 결과의 정규화 해시와 모든 선택 답안은 그대로이며 모델 재풀이 없이 동일 검사를 다시 통과했다.
