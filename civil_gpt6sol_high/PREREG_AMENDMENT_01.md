# 사전등록 보정1 — CLI 시작 안내의 도구감사 분류

작성시각: 2026-09-23T07:01:26.530455+00:00

도구 미사용1회차의 첫5개 호출 진행 중, Codex가 `skip_host_skill_discovery` 실험적기능 안내를 모델턴 시작 전에 `item.type=error`로 기록함을 확인했다. 이 안내는 모델의 도구호출이 아니나 기존 엄격감사에서 이를 도구이탈로 잘못 거절한다.

실제 풀이·응답은 열람하지 않은 상태에서 해당 CLI 시작안내만(턴 시작 이전·고정된 메시지 접두어) 허용하도록 감사기 수정. 모델·추론강도·프롬프트·질문·허용도구는 변경하지 않는다. 첫5개 호출이 종료코드0·정상최종턴·JSON검증·수정감사를 모두 통과하면 원응답을 기계적으로 봉인하며 재추론하지 않는다. 하나라도 실제실패하면 기존재개규칙 적용. 원로그·원응답 전부 보존.

후속실행은 수정감사기와 갱신된해시를 사용한다. 채점과정은 이 보정을 공개한다.
